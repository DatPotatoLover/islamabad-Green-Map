How to use the map

  1. Wait for the API data to load.
  2. Search for a place by name or select a feature type.
  3. Click a marker to view its name, type, and coordinates.
  4. Use the refresh button if the public API is temporarily unavailable.

API and data fields

API: Overpass API (OpenStreetMap)

Fields used: name, leisure, latitude, longitude, and center coordinates for mapped areas.

Access: Public endpoint; no API key is required for this demonstration. Please use it responsibly.
